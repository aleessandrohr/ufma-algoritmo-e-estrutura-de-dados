# *Avaliação da Cafeteria* :coffee:
P1 de algorítimos e estrutura de dados 

# *Sobre o projeto*

Programa desenvolvido em linguagem C para cadastrar e gerenciar avaliações de uma cafeteria, utilizando um menu interativo no terminal.

# *Funcionalidades*

- **Adicionar:** cadastra notas de 1 a 5, com limite de 10 avaliações.
- **Mostrar:** exibe todas as avaliações cadastradas.
- **Buscar:** procura avaliações específicas.
- **Atualizar:** modifica uma avaliação existente.
- **Remover:** exclui a última avaliação cadastrada.
- **Relatório:** apresenta a média, a quantidade de votos por nota, a maior e a menor avaliação.
- **Sair:** encerra o programa.

# *Tecnologias*

- Linguagem C
- Bibliotecas `stdio.h` e `stdbool.h`

# *Como executar*
Compile o programa com o GCC:

```bash
gcc main.c -o avaliacao_cafeteria
```

**Linux:**

```bash
./avaliacao_cafeteria
```

**Windows (CMD ou PowerShell):**

```bash
avaliacao_cafeteria.exe
```

Vetores, estruturas condicionais, laços de repetição, validação de dados e operações CRUD (*Create, Read, Update, Delete*).
