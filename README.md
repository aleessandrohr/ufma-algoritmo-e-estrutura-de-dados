## 🛠️ Sobre o Projeto CRUD (P1)

O projeto localizado na pasta `/crud` é uma aplicação desenvolvida em **C** que funciona via terminal. Ele implementa as quatro operações básicas do sistema, aplicando os conceitos de estruturas de dados vistos na disciplina:

* **C**reate (Criar): Adição de novos registros no sistema.
* **R**ead (Ler/Consultar): Listagem e busca de registros salvos.
* **U**pdate (Atualizar): Modificação de dados de um registro já existente.
* **D**elete (Remover): Exclusão de registros do sistema.
